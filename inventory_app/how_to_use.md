# 在庫管理アプリの使い方

## 1. このアプリでできること

Tシャツ・キャップ・カバン・バッジなどの在庫を、スマホやタブレットのブラウザから記録するアプリです。在庫は2種類に分けて管理します。

| 種類 | 意味 | 例 |
|---|---|---|
| **無地在庫** | 仕入れたままの、プリント前の商品 | 黒・Mサイズの無地Tシャツ 10枚 |
| **プリント済み在庫** | プリントして完成した商品 | 「ねこロゴ」を刷った黒・MのTシャツ 8枚 |

**数字は「入荷」「プリント変換」「出荷・調整」の3つの操作でだけ変わります。** 画面の数字を直接書き換えることはできません。操作をするたびに、いつ・誰が・何をしたかが履歴に残ります。

## 2. 言葉の整理

- **カテゴリー**: 商品の大分類(Tシャツ、キャップなど)。カテゴリーごとに「色を使う」「サイズを使う」などの入力欄の設定があります。たとえばバッジは種類名だけで、サイズは使いません。
- **品番**: 仕入れる商品1種類のことです(ブランド+品番+商品名)。例: Printstar 085-CVT
- **色・サイズ・種類名**: 同じ品番の中の違いです。「黒のM」と「白のL」は別々に数えます。

## 3. ログインと画面の見方

ユーザー名とパスワードでログインします。上のメニューから各画面に移動します(スマホでは右上の「≡」を押すと開きます)。

ユーザーには2種類あります。

- **スタッフ**: 在庫の入荷・変換・出荷・調整、履歴の確認、備考の記入ができます。
- **管理者**: 上に加えて、品番・カテゴリー・ユーザーの管理ができます(メニューに「品番」「カテゴリー」「ユーザー」が出ます)。

右上のユーザー名を押すと、自分のパスワードを変更できます。

## 4. 画面ごとの説明

### ダッシュボード(最初の画面)
- カテゴリーごとの在庫の合計が、カード形式で見られます。カードを押すと、そのカテゴリーの無地在庫の画面に移ります。
- 「未対応の備考」と「直近の操作」(最新8件)も表示されます。

### 無地在庫
- 上のタブでカテゴリーを切り替えます。検索欄では、ブランド・品番・商品名で絞り込めます。
- 品番ごとに、色(行)×サイズ(列)の**表**で在庫が見られます。
- 数字の色の意味は次のとおりです。
  - 在庫が **0**: ゼロ用の色で表示されます。
  - 在庫が **3枚以下**: 「残りわずか」の色で表示されます。
  - **「–」**: まだ一度も入荷していない組み合わせです。
- 「この品番を入荷」ボタンで、その品番が選ばれた状態の入荷画面に進めます。

### プリント済み
デザインごとにまとめて、在庫が一覧で見られます。上の検索欄では、デザイン名・品番・色で探せます。

## 5. 操作の手順

### 入荷(商品が届いたとき)
1. メニューの「入荷」を開きます。
2. **品番**を選びます。選ぶと、その品番に必要な入力欄(色・サイズ・種類名)だけが表示されます。
3. **色・サイズ**などを入力します。色とサイズには、過去に使った候補が出ます。
4. **数量**を入力します。
5. 必要なら**メモ**(納品書番号など)を書きます。
6. 「入荷を登録」を押します。成功すると緑のメッセージが出ます。

ポイント:
- 初めての色やサイズでも、入力すれば自動で作られます。**事前の登録は要りません。**
- 使用停止中の品番には入荷できません。
- 数量は1以上の整数です。1回に入れられる上限は100万です。
- 色の書き方が揺れると、別の在庫として数えられます(「黒」と「ブラック」など)。**書き方は統一しましょう。**

### プリント変換(無地を使ってプリント済みを作るとき)
1. メニューの「プリント変換」を開きます。
2. **使う無地在庫**を選びます(現在の在庫数も表示されます)。
3. **デザイン**を選びます。新しいデザインなら、下の欄に新しい名前を入力します。
4. **使用数**(無地から減る数)を入力します。
5. **完成数**(プリント済みに増える数)を入力します。
6. 「変換する」を押します。

ポイント:
- **ミスプリントがあったら、使用数と完成数を別々に入力します。** 例: 10枚使って完成が9枚なら、使用数10・完成数9です。
- 完成数が使用数より多い入力はできません。
- 完成数は0でも構いません(全部失敗した場合)。
- プリント対象でないカテゴリー(バッジなど)は、変換できません。

### 出荷(売れた・送ったとき)
1. メニューの「出荷・調整」を開きます。
2. 操作で「**出荷**」を選びます。
3. **対象の在庫**を選びます。プリント済みと無地の両方が選べます。
4. **数量**を入力します(プラスの数で入力します。自動で減ります)。
5. 「登録」を押します。

### 棚卸し調整(数え直して、数字が合わないとき)
1. 「出荷・調整」で、操作に「**棚卸し調整**」を選びます。
2. 対象の在庫を選びます。
3. 数量に、**ずれの分だけ**入力します。実際のほうが多ければ「+3」、少なければ「-2」です。
4. **理由を必ず**入力します(例: 「10/6 棚卸しで3枚多かった」)。
5. 「登録」を押します。

ポイント: 「実際の数」ではなく**「差分」**を入れます。現在庫が12で実際は10なら、「-2」です。

### 履歴の確認
- 「履歴」を開くと、日時・操作・対象・増減・担当者・メモが新しい順に出ます。
- 上の選択欄で、「入荷だけ」「出荷だけ」のように絞り込めます。
- 時刻は日本時間で表示されます。

### 備考(メモ)を残す
仕入れ先の変更や「この色は入荷が最後」のような連絡事項を、品番ごとに残せます。
1. 「無地在庫」で、品番のカードにある「備考を追加」を押します。
2. 内容を書きます。特定の色の話なら「対象の色・種類」も選びます。
3. 保存します。

ポイント:
- 対象の色を選ぶと、その行に「備考」の印が付きます。空欄なら品番全体へのメモです。
- 未対応の備考は、ダッシュボードと入荷画面にも出ます。片付いたら「対応済みにする」を押します(戻すこともできます)。
- 削除できるのは管理者だけです。

## 6. 管理者向けの操作

### 品番を追加する
1. メニューの「品番」を開きます。
2. 下の「品番を追加」で、カテゴリー・ブランド・品番・商品名を入力します。**ブランドか品番のどちらかは必須です。** 商品名は任意です。
3. 「追加」を押します。

品番の「編集」では、内容の変更と、**使用中のオン・オフ**ができます。もう仕入れない品番はオフにします。オフにしても、残っている在庫の出荷や調整はできます。

### カテゴリーを追加・設定する
「カテゴリー」で追加・編集します。次の項目を設定します。

| 設定 | ONにすると |
|---|---|
| 色を使う | 入荷画面に「色」の欄が出る |
| サイズを使う | 入荷画面に「サイズ」の欄が出て、在庫表に列が並ぶ |
| 種類名を使う | 入荷画面に「種類名」の欄が出る(デザイン違いなど) |
| プリント対象 | プリント変換の候補に出る |

すでに在庫があるカテゴリーでは、使っている項目(色・サイズ・種類名)をOFFにできません。データを守るためです。

### ユーザーを管理する
「ユーザー」で、追加(パスワードは8文字以上)、有効・無効の切り替え、パスワードの再設定ができます。パスワードを再設定すると、その人がログインしていた**全端末が自動でログアウト**されます。端末をなくしたときに使えます。

## 7. 間違えたときは

**入荷・出荷・変換を「取り消す」ボタンはありません。** 間違えたら、「出荷・調整」の**棚卸し調整で逆の操作**をして直します。履歴には、間違いも修正も両方残ります。

| 間違い | 直し方 |
|---|---|
| 入荷を10枚多く入れた | 「棚卸し調整」で、-10(理由: 入荷の入力ミス) |
| 出荷を入れ忘れた | 「出荷」で登録する |
| 変換の数を間違えた | 無地とプリント済みの両方を、それぞれ棚卸し調整で直す |

在庫がマイナスになる操作は、「在庫が足りません」と表示されて実行されません。

## 8. 1日の流れの例

1. **朝**: ダッシュボードで在庫と未対応の備考を確認します。
2. **商品が届いたら**: 「入荷」で登録します(納品書番号をメモに書きます)。
3. **プリントしたら**: 「プリント変換」で、使用数と完成数を入力します。
4. **売れたら**: 「出荷・調整」で、プリント済みの在庫から減らします。
5. **月末など**: 実際に数えて、ずれた分を棚卸し調整で直します。
